# direct-casting

アルミニウム DC（Direct Chill）鋳造ラインの 3D シミュレーター。`index.html` をブラウザで開くだけで動きます（three.js r128 / Font Awesome を CDN から読み込み）。

## 設備構成

| 設備 | 内容 |
| --- | --- |
| 鋳造炉（溶解・固定式反射炉） | スクラップ装入 → バーナー溶解 → 電磁攪拌・除滓 → 出湯 |
| 保持炉（固定式） | 移湯樋で受湯 → Ar ガス脱ガス・鎮静 → 出湯口から鋳造機へ |
| 溶湯処理 | インライン脱ガス装置（回転ローター 2 槽）→ CFF フィルター |
| 鋳造機（3 本鋳込み） | 傾動式鋳造テーブル・水冷モールド ×3・プラテン／油圧ラム・鋳造ピット |
| 天井クレーン | スラブトングでスラブを吊り上げ、通路のスラブ置場へ横倒し |
| スクラップ装入機 | スクラップヤードで積込み → 炉扉から装入、除滓したドロスをドロス受けへ排出 |

## 工程

- **溶解ライン**：スクラップ装入（2〜4 回）→ 溶解 → 攪拌・除滓 → 出湯待機 → 移湯 → 保持炉で脱ガス・鎮静
- **鋳造ライン**：鋳造準備 → 注湯開始 → 定常鋳造 → 鋳造終了 → テーブル傾動 → スラブ引上げ → クレーン搬出・横倒し → 段取り復帰

2 つのラインは並行して動き、鋳造中に次ヒートの溶解が進みます。

## 操作

- 左ドラッグ：回転／右ドラッグ：平行移動／ホイール：ズーム（タッチ操作にも対応）
- 右上：再生速度（×0.5〜×8）、一時停止、最初からやり直し、パネル表示切替
- 左パネル：鋳造速度・冷却水量・目標鋳造長・鋳込み本数・装入回数・出湯温度、表示切替、視点プリセット
- 「自動カメラ」オンで工程に合わせて視点が追従します（手動操作するとオフになります）
